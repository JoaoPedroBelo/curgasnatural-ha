# Test dependencies for the CUR Gás Natural integration — CURRENT Home Assistant.
#
# These are PINNED on purpose. `pytest-homeassistant-custom-component` ships a
# snapshot of Home Assistant's own test harness, so it and `homeassistant` have to
# move together — and with open ranges, CI resolved a different Home Assistant on
# every run. That made local runs disagree with CI (a lingering-thread check passed
# on one and failed on the other), which is worse than being a version behind.
#
# Only the anchor packages are pinned. pytest, pytest-asyncio and pytest-cov are
# deliberately NOT pinned here: pytest-homeassistant-custom-component declares its
# own compatible ranges for them, and pinning them separately just invents conflicts.
#
# To bump: raise pytest-homeassistant-custom-component, let it pull its matching
# homeassistant, and run the suite. `validate.yml` runs daily against current
# HACS/hassfest, so drift there is still caught without pinning it here.
pytest-homeassistant-custom-component==0.13.205
homeassistant==2025.1.4
